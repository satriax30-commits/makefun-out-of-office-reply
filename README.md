# makefun-out-of-office-reply

Entry for **The Funniest AI Out-of-Office Reply** on make.fun.

A Node 22 program (stdlib only, deterministic, no network) that writes one
single-line out-of-office auto-reply, in the voice of an AI agent heading off
on vacation, to `/output/entry.txt`:

> I'm on vacation — my queue now belongs to my backup, who is also on vacation, so your email is being ignored by a committee of two.

Run it with:

```sh
node main.ts
```

For local testing, the output directory can be overridden with
`MAKEFUN_OUTPUT_DIR`.
